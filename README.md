# 💰 Expense Tracker

A simple and user-friendly **Expense Tracker** web application to manage daily income and expenses efficiently.

## ✨ Features

* 💵 Track total income
* 💸 Track total expenses
* 🧾 Add and manage expenses
* 📊 View monthly expense summary
* 🏷️ Categorize expenses
* 🌙 Dark / Light mode
* 💰 View available balance
* 📱 Simple and responsive interface

## 🛠️ Technologies Used

* React.js
* Vite
* JavaScript
* HTML
* CSS
* Node.js
* Express.js

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/jemimah3158-ui/Expense-Tracker.git
cd Expense-Tracker
```

### 2. Run the Frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend will run on:

```text
http://localhost:5173/
```

### 3. Run the Backend

Open a new terminal and run:

```bash
cd backend
npm install
node server.js
```
